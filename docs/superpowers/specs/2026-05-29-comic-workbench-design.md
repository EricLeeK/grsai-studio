# 论文讲解漫画工作台设计规格

## 目标

在保留现有默认生图工作台入口的前提下，新增一个可从功能中心进入的“论文讲解漫画”子功能。该子功能用于按漫画项目组织封面、数字页和尾页的生成结果，支持每页多个候选图、选定本页成稿、常驻提示词、IP 参考图自动引用，以及适配漫画元数据的一键复刻。

## 导航与 Logo

- `/` 继续直接进入现有生图工作台，不改变用户打开网站后的默认路径。
- 新增 `/apps` 功能中心页面，用于选择进入“生图工作台”“论文讲解漫画”“公众号发布”等子功能。
- 现有 header 增加进入功能中心的入口。
- 浏览器标签页 favicon 使用现有左上角绿色 `G` 字样的简化图标，作为静态 SVG/ICO 提供。

## 漫画项目

采用轻量“漫画项目”概念。一个项目代表一篇论文漫画，漫画页面和候选图都归属于当前项目，避免多篇论文的页码和候选混在一起。

v1 默认自动创建或使用最近一个漫画项目，页面上提供项目名称显示和简单的新建/切换能力。更完整的项目管理可以后续扩展。

## 页面与候选模型

漫画页类型分三类：

- `cover`：封面页。
- `numbered`：数字页，页码为 1-20 的阿拉伯数字。
- `tail`：尾页。

每个漫画页可以有多个候选图。候选图来自普通生成任务的输出图片，并记录：

- 所属漫画项目。
- 页类型和页码。
- 对应任务 ID 和生成图 ID。
- 候选顺序。
- 是否为本页选定图。

如果某页只有一个候选图，默认自动选定为本页图。用户也可以点击“选定此图为本页”在候选中切换选定图。

## 漫画生成配置区

左侧配置区沿用现有生图配置区的模型、尺寸、质量、数量、并行、临时参考图、持久参考图库、粘贴图片和提交行为。

新增漫画专属配置：

- 页面选择：封面页、数字页、尾页。
- 选择数字页时，必须输入 1-20 的页码。
- 固定 IP 模式开关。
- IP 设定图库：与普通参考图库类似，但属于漫画工作台的常驻 IP 图；开启固定 IP 模式时自动勾选并随任务提交。
- 常驻提示词库：分为封面页、数字页、尾页三个分组。
- 每条常驻提示词有“复制、使用、删除、发送时自动添加到尾部”功能。
- 自动添加开关为前端会话态：页面刷新后重置；在不刷新页面的情况下，切换主页面或其他子功能后保持。
- 发送漫画任务时，会按当前页类型筛选开启的常驻提示词，按列表顺序追加到用户 prompt 后面。

## 右侧预览区

漫画工作台右侧提供两个模式：

- 漫画预览。
- 生成列表。

生成列表复用现有主页面任务列表展示和筛选行为，但不改变左侧漫画配置区。

漫画预览模式：

- 只展示已有候选的页面，不为无候选页面预留位置。
- 当前页面显示为中心大图。
- 左右相邻页面以较小、变暗、位于当前图层后方的方式显示。
- 点击左/右侧预览图时切换当前页，旧当前页平滑滑向对应方向。
- 每页候选图通过上下按钮切换；非当前候选不可见，不做上下虚影。
- 大图下方显示页导航框，标明当前是封面/第几页/尾页，并提供可点击的已有页面快速跳转。
- 当前大图右下角提供“选定此图为本页”。只有一个候选时默认选定。

## 任务与复刻

漫画生成任务本质仍创建普通任务，但任务 `params` 里附加漫画元数据：

- `comic_project_id`
- `comic_page_type`
- `comic_page_number`
- `comic_ip_mode`
- `comic_auto_prompt_ids`
- `reference_image_ids`
- `ref_image_paths`

任务完成后，生成图片作为对应漫画页候选图进入项目预览。

任务卡片上的“一键再来一个”在漫画工作台中要回填所有漫画元数据，包括项目、页类型、页码、IP 模式、参考图、常驻提示词开关相关状态，以及普通模型参数。

## 错误处理

- 数字页页码缺失或不在 1-20 时阻止提交并提示。
- 漫画项目不存在时自动创建默认项目。
- 引用图片不存在时沿用后端现有 404 行为。
- 任务失败时仍在生成列表显示失败，不进入漫画候选预览。

## 测试策略

- 后端测试漫画项目、漫画候选记录、页码验证、任务元数据保存。
- 前端至少用 JS 语法检查和浏览器快检验证页面加载、模式切换、复刻按钮存在。
- 继续保留现有 `.venv/bin/pytest -q` 作为完整回归。
